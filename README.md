# 🎈 Puff & Pop

A pointless volume adjuster for **Project Paradox - Christmas Edition** (IEEE CIS Student Chapter, KLS GIT).

Because a slider is too logical. Inflate your way to louder sound.

## Concept
Instead of a volume slider, you adjust the volume by pumping air into a virtual balloon. The balloon size is the volume. At 100% the balloon explodes with a comic POP, confetti and a popping sound, and the volume resets to 0%.

## Features
- PUMP IT and RELEASE AIR buttons, with funny pump and deflate sound effects
- A balloon with a face that goes from happy to nervous to panicking as it fills
- Funny system messages in a speech bubble
- Chaos Mode: random pump sizes and random colour changes
- Silly statistics: Drama level and Neighbour concern
- Test Sound: a retro arcade tune whose loudness and pitch follow the balloon (Web Audio API)
- RESET THE UNIVERSE button

## Built with
HTML, CSS, JavaScript and the Web Audio API. No external libraries.

## Run locally
Open the folder in VS Code and start `index.html` with the Live Server extension.
